# עיצוב: שחזור תמונות (Stitch)

פרויקט Stitch: "Photo Restoration"
https://stitch.withgoogle.com/projects/10679439342850365369

ארבעה מסכים בעברית (RTL), בסגנון ארכיוני וחם: שמנת, חום כהה והדגשה בכתום-נחושת.
המסכים נוצרו בגרסת מובייל (רוחב 390px). בכל מסך שלושה קבצים לפי המספר: `.html` (קוד Stitch) ו-`.png` (צילום מסך). הקבצים ב-`stitch/`.

## 1. העלאה
אזור גרירה להעלאת תצלום יחיד, מחוון התקדמות, כפתור התחלה, והסבר ש"קובץ המקור נשמר תמיד בשלמותו".

## 2. בטיפול
סטטוס שלבי העיבוד של הקובץ שהועלה (בדיקת תקינות, ניקוי וחידוד, השוואה למקור), תחת הכותרת "שלבי הרסטורציה המדעיים".

## 3. תוצאה
מקור ותוצאה זה לצד זה עם מחוון הזזה ("משווה שחזור דיגיטלי אינטראקטיבי"), תג סטטוס (הושלם / לבדיקה / נכשל), כפתור הורדה, וממצאי טיפול ומדדים.

## 4. דוח
תקציר פעולות שימור ומפת טיפול (מה נעשה והיכן), כלים והגדרות, מפת אי-ודאות עם אזורים מסומנים, והמלצה לבדיקה אנושית.

## הערות לגבי הסטייה מהמפרט
- המסכים הופקו במובייל ולא בדסקטופ.
- ערכת הנושא בפרויקט משתמשת ב-Noto Serif ו-Noto Sans, ולא ב-Heebo כפי שנדרש.
- ב-Stitch נוסף תוכן שאינו ב-MVP (spec §5), למשל בחירת סוג תצלום ותקופה במסך ההעלאה, ופירוט טכני מורחב במסכי התוצאה והדוח. יש לצמצם אותו ליישום.
- הכותרת בראש מסך ההעלאה באנגלית ("Artifact Inspection Detail").
- קיים בחשבון Stitch פרויקט נוסף באותו שם (`13257581177964866556`) שנוצר בניסיון הראשון והוא ריק. מומלץ למחוק אותו.
